# 로컬라이징 문체 가이드

번역 · 검수용 기준 문서. 용어는 `Glossary.csv`를 따름

- 기준 게임: **Slay the Spire 2 공식 번역**, StS2에 없는 표현은 하스스톤 공식 번역 참고 (둘이 다르면 StS2)
- 한국어 원문은 `Assets/Resources/JsonData`(카드 · 버프 · 키워드 · 캐릭터 · 몬스터)와 `Assets/Resources/Localization/ko/ui.json` · `intents.json`
- 번역문은 `Assets/Resources/Localization/<언어 코드>/*.json` (키 = 한국어 표와 같은 키)
- 상태: 모든 번역은 **원어민 검수 전 초안**

## 1. 공통 규칙

### 1-1. 문구 표기

| 표기 | 의미 | 번역 시 |
|---|---|---|
| `{attack}` `{block}` `{amount}` `{stack}` `{damage}` 등 | 실행 중 바뀌는 값 | 이름 그대로 유지, 위치는 언어에 맞게 이동 |
| `{stack장}` `{stack회}` | 한국어 단위가 붙은 값 | 다른 언어에서는 `{stack}` + 복수형 사용 |
| `{n, plural, one {…} few {…} many {…} other {…}}` | 복수형 (ICU) | 필요한 언어만 사용. `#` = 수, `=1` 같은 정확한 값 분기 가능 |
| `[buff:4001]` | 버프 이름 (현재 언어 이름 + 색 · 툴팁) | 그대로 둠. 이름 위치만 어순에 맞게 |
| `[buff:4001\|уязвимости]` | 버프 이름을 문장에 맞는 형태로 덮어씀 | 격변화 · 축약이 필요할 때만 (러시아어 생격, 독일어 형용사 어미 등) |
| `[keyword:1]` `[card:101010]` | 키워드 · 카드 이름 | 그대로 둠 |
| `{runeBuff}` | 우피 모드에 따라 바뀌는 버프 이름 | 그대로 둠 |
| `"…"` 큰따옴표 안 문구 | 조각 카드가 새기는 효과 문구 (코드가 따옴표 안을 잘라 씀) | **`"…"` · `“…”` · `「…」` 중 하나만 사용** (러시아어 «…», 독일어 „…" 은 인식되지 않음) |

- 줄바꿈(`\n`)은 넣지 않음 (카드 칸에서 자동 줄바꿈)
- 한국어 조사는 `[buff:…]`, `{인자}` 바로 뒤에 `을/를` 중 아무거나 써도 받침에 맞게 자동 보정
- 작은따옴표는 특수 기호가 아님 (`d'Armure` 그대로)
- 복수형에서 1일 때 숫자를 빼고 싶으면 `=1` 분기 사용 (en "Your next card" / "Your next {stack} cards"). 러시아어 `one`은 21 · 31에도 쓰이므로 숫자를 빼면 안 됨
- 카드 툴팁(카드에 붙은 버프 설명)은 중첩 수치를 모르므로 `{stack}`이 한국어에서는 지워지고 다른 언어에서는 `X`로 표시됨 → `{stack}` 앞뒤 문장이 `X`로도 자연스럽게
- 검증: 에디터 `Tools/Localization/번역 검증` (테스트 `Tests/Localization`도 같은 검사), 화면 확인은 플레이 중 `의사 언어 켜기 · 끄기`

### 1-2. 시점

| 대상 | 시점 | 예 |
|---|---|---|
| 카드 · 아이덴티티 | 플레이어가 하는 행동 | en "Deal 6 damage." |
| 버프 설명 | 보유자 기준 서술 (플레이어 · 몬스터 공용) | en "Takes 25% more damage." · 플레이어 전용은 "At the start of your turn, …" |
| 몬스터 의도 문장 | **몬스터가 주어인 3인칭**, 한국어 원문의 "적" = 플레이어 → 2인칭 | en "Deals 10 damage." · "Adds 1 Wound to your Hand." |
| UI | 짧은 명사 · 동사 (버튼은 동사) | en "End Turn", "Save Deck" |

- 몬스터 의도를 3인칭으로 하는 이유: 명령문(en "Deal 10 damage.")은 플레이어의 행동으로 읽힐 수 있음 (사용자 결정 D8, 언어별로 오해 소지가 없으면 그 언어 관례 우선)

### 1-3. 숫자 · 기호

- 숫자는 아라비아 숫자 그대로 (zh "两张" 같은 한자 숫자 쓰지 않음, StS2와 같음)
- 퍼센트: en/ja/zh/ru `25%`, fr/de `25 %` (공백)
- 로마 숫자 계층(I~IV)은 모든 언어 그대로

## 2. 언어별

### en (영어)

- 카드: 명령문, 주어 없음 — "Deal {attack} damage. Apply 2 [buff:4001]."
- 키워드 · 버프 · 게임 용어는 대문자 시작 (Block, Exhaust, Draw Pile, Hand)
- 복수형: `{n, plural, one {card} other {cards}}`
- 모든 적: "ALL enemies" (StS2 강조 표기)
- 이번 턴 / 이번 전투: "this turn" / "this combat"
- 문장 끝 마침표

### ja (일본어)

- 보통체(사전형) + 。 — 「{attack}ダメージを与える。」「カードを2枚引く。」
- 버프 부여: 「[buff:4001]2を付与する。」(StS2: 弱体2を付与する), 획득: 「[buff:3012]3を得る。」
- 조수사: カード 枚, 몬스터 体, 횟수 回
- 띄어쓰기 없음, 쉼표는 、
- 키워드 · 용어는 Glossary (廃棄, 保留, 山札, 捨て札, 手札)

### zh-Hans (중국어 간체)

- 동사 앞 + 양사 + 。 — 「造成{attack}点伤害。」「获得{block}点格挡。」「抽2张牌。」
- 버프 중첩은 层: 「给予2层[buff:4001]。」, 획득은 「获得3层[buff:3012]。」
- 전각 문장부호 (，。：；（）), 숫자 앞뒤 공백 없음
- "你" 사용 (StS2: 你的手牌)

### zh-Hant (중국어 번체)

- 간체와 문장 구조는 같고 **용어 · 글자가 다름** (別途 번역, 자동 변환 금지)
- StS2 번체 관례: 숫자 앞뒤 공백 — 「造成 {attack} 點傷害。」「抽 2 張牌。」
- 施加(부여) · 層 · 點 · 張 · 棄牌堆 · 抽牌堆 · 手牌

### ru (러시아어)

- 카드: 3인칭 서술 — "Наносит {attack} урона." "Дает {block} защиты." 뽑기는 "Вы добираете 2 карты."
- 복수형 3종 필수: `{n, plural, one {карту} few {карты} many {карт} other {карт}}`
- 버프 부여 · 획득은 수 + 생격: "Накладывает 2 [buff:4002|уязвимости]." → 격변화가 필요하면 `[buff:id|형태]`
- 모든 적: "ВСЕМ врагам" (여격, 대문자 강조)
- 체력: ОЗ, 에너지: энергия
- ё는 е로 써도 됨 (StS2는 е 사용: "Дает")

### fr (프랑스어, 추후)

- vous 명령형 — "Infligez {attack} dégâts." "Gagnez {block} d'Armure." "Piochez 2 cartes."
- 버프 부여: "Appliquez [buff:4002] ({n})." (StS2 방식)
- `:` `;` `!` `?` 앞 공백

### de (독일어, 추후)

- du 명령형 — "Füge {attack} Schaden zu." "Erhalte {block} Block." "Ziehe 2 Karten."
- 분리동사 위치 주의 (Füge … zu, Wirf … ab)
- 문장이 길어지므로 카드 칸 확인 필요
